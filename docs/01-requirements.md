# 需求与验收

用户是需要查询制度或产品信息的员工。输入为问题和可选对话历史，输出为回答、证据文档 ID、版本和原文、资料缺口、状态及运行记录。资料均为合成 FAQ 和制度，不连接真实企业数据。项目不维护对话存储，用户以 JSON 显式传入本轮所需历史。

验收覆盖明确答案、文档冲突、资料外问题、改写的相似问题、上下文追问、工具失败；补充了资料替换、答案与问题属性不匹配、错误引用、工具调用限制和格式错误。实际输出和证据见 [评估](03-evaluation.md)。

成功标准是：模型选择查询、读取或其他后续动作；回答仅基于本轮读取的原文，无法支持全部问题时说明缺口；冲突须展示不同资料及原文并请求确认，不根据版本日期自行选择。限定为有限合成语料的原型，不声称已解决任意开放域知识问答。
